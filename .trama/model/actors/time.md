# Time

The passing of time. Weaver uses it only to look at omp again; it never uses it to decide that an agent stopped working.

## Events

### RECHECK_DUE
A few seconds have passed while Weaver waits for omp's installer or a provider login running in the system terminal.

### UPDATE_CHECK_DUE
An hour has passed since Weaver last asked omp whether a newer version exists.
